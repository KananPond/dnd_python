## 一、一句话世界观

阿瑟兰大陆的浮空帝国在一千年前因窃取神力而坠落，主城**阿斯凯隆**埋进地底，被疯法师改造成十层竖井。
玩家是这一代的**逐光者**：下到第十层，把还在转动的**星核之心**（深渊遗物）带回地表。

## 二、阿瑟兰大陆（Atheran）

诸神与凡民比邻而居的大陆。法术像阳光一样随处可见，四个主要族群各有家园：

| 族群 | 家园 | 一句话 |
|---|---|---|
| 人类 | **银冠诸国**（Silvercrown） | 白石城邦、议会石厅、行会账本、按日结算的雇佣兵市场 |
| 精灵 | **星落林**（Starfall Wood） | 千年古木与月光；唯一记得断裂之夜全貌的族群 |
| 矮人 | **深炉山脉**（Deepforge） | 为穹顶帝国凿出第一批竖井，也第一批被活埋；煤与铁的锻炉文明 |
| 侏儒 | **齿轮谷**（Cogvale） | 为星核设计最初的齿轮与符环；能听见织线的杂音 |

大陆中央是**灰原**（Ashenreach）：阿斯凯隆坠落砸出的荒原，雷暴终年不散，深渊之门就在这片荒原上。

## 三、穹顶帝国与断裂之夜

- **穹顶帝国**：七座浮空城悬在云上，主城**阿斯凯隆**。帝国法师能让河流改道、让时间在庭园里打弯。
- **星核**：帝国的动力与法术之源——把**织线**（世界魔力的源流）缚进水晶的技艺。每座浮空城靠一颗星核悬浮。
- **织线 / 织法者 · 薇兰**：织线是法术的源流，由女神薇兰照看。帝国能如此强大，靠的是织线尚在。
- **断裂之夜**：帝国最强大的大法师**奥兰**试图越过界限、亲手攫取薇兰的权柄。织线在那一声崩断里碎了；
  七座浮空城同时失去支撑坠向大地，主城阿斯凯隆砸进灰原，把方圆百里的山川一起压入地底。
- 帝国的名字从此成了一个不许提起的咒。

## 四、遗忘之陆：灾后的地表

劫难之后诸神退回星界，连接诸界的门扉一扇扇闭合，阿瑟兰从异邦的传说与地图上消失——后世叫它**遗忘之陆**。

银冠诸国在废墟上重建：议会的石厅、行会的账本、雇佣兵市场里按日结算的剑。但织线再没回到昔日的丰饶：

- 法术成了稀罕、危险、**需要登记**的东西；法师这一派被列在"需要登记的法术使用者"名单第一行。
- 大部分人对星核又怕又馋：一句是"别碰深渊"，另一句是"可深渊里的东西能让你一夜暴富"。
- 星落林里的星冠精灵守着一千年前那点织线余温，一直劝人别去碰那座坠城。

## 五、深渊地牢（十层）

阿斯凯隆没有死去，它只是沉了下去。坠城的尖塔、地窖与星核残骸彼此堆叠，被**没有在断裂之夜死去的
疯法师奥兰**一层层改造成陷阱与魔物盘踞的竖井——**整整十层，越深越靠近当年帝国的核心**。

- **深渊之门**：每隔几代人，封印会松一次，星核之心在地底发出微光，灰原上的门随之开启。
- **逐光者**：门开时从各地赶来的冒险者。下井前会往幸运之女的箱子里丢一枚硬币——一种讨彩头的习惯。
- **层数**：一至十层，怪物与宝物都按深度分层；越深越险，值钱的东西也越好。
- **奥兰**：他仍然活着，也仍然在改这座地牢。没人知道他究竟想守住什么。

## 六、深渊遗物与深渊守卫

- **深渊遗物（古称「星核之心」）**：阿斯凯隆的浮空动力核心，坠落后仍在地下缓缓转动。
  它牵动地表的一切异常——法术失灵、灰原不散的雷暴、地牢里不断新生的怪物。
- **深渊守卫**：奥兰用帝国最坚硬的符文打出来的看门构造体。不会疲倦，也不会真正死去——
  被打散之后仍会重新拼合。**正面硬拼打不过，唯一的办法是把它引开**，再去拿遗物。
- **拿到即胜利**：游戏机制上，遗物就放在守卫身边（不压在它脚下），取得遗物即通关，不必杀死守卫。
- 把星核之心带回地表会怎样，设定上刻意留白：可能是织线重新丰饶，也可能是把一千年前的坠落重新带回人间。

## 七、诸神

| 名讳 | 司掌 | 简述 |
|---|---|---|
| **织法者 · 薇兰**（Vyran） | 织线、魔法 | 法术是她手中未断的线。断裂之夜后，她的神殿被重建，也被猜忌 |
| **晨光之主 · 艾尔登**（Aeldan） | 黎明、新生 | 下井的人多半向他祈祷，因为地底没有太阳 |

| **锻炉之父 · 瓦尔格**（Vargr） | 锻炉、矮人 | 他教会凡民在星核熄灭之后，仍用煤与铁把日子打出来 |

## 八、种族

## 十、时间线

| 时期 | 事件 |
|---|---|
| 远古 | 诸神与凡民比邻而居；法术像阳光一样常见 |
| 帝国期 | 穹顶帝国建成七座浮空城，以星核抽取织线之力；矮人替它凿竖井，侏儒替它造齿轮 |
| **断裂之夜**（约一千年前） | 奥兰攫取薇兰权柄 → 织线崩断 → 七城坠地 → 阿斯凯隆埋入灰原 |
| 灾后 | 诸神退回星界、门扉闭合 → 遗忘之陆；银冠诸国重建，法术转为登记制 |
| 之后每几代人 | 封印松动、深渊之门开启，逐光者下井 |
| **现在** | 门又开了。玩家（`{name}`）站在门前 |

## 十二、写作边界（改文案前先读）

1. **游戏内只讲三件事**：世界背景、玩家如何进地牢、下井须知（十层 / 遗物 / 守卫 / 永久死亡）。
   其余一律留本文——序章的定位是"进场说明"，不是设定集。
2. **名词全部自创**：不出现任何他方商标与专有名词；这条线由
   `tests/test_core.py::TestLore::test_story_text_has_no_wotc_proper_nouns` 自动扫描游戏文本守住。
3. **两处要同步**：改游戏内文案 → `dnd/data/lore.json`；改完整设定 → 本文。
4. **世界观可整体替换**：`dnd/data/lore.json` 与本文都是 CC0-1.0，想换成自己的设定不需要改一行代码。
