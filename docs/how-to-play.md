# 怎么游玩 · dnd 上手指南

> 面向第一次打开游戏的玩家。安装/开发说明见 `README.md`，机制出处见 `docs/research-dossier.md`。

## 0. 前置条件

- **必须是真实终端**：Linux / macOS 的终端，或 Windows 上的 **WSL2** 终端（Windows 原生 cmd/PowerShell **不支持** curses）。
- Python ≥ 3.10（开发用 3.14）。**不需要装任何第三方包**。
- 建议终端窗口 **≥ 100 列 × 30 行**（宽度 ≥ 100 会多出一整栏"冒险者档案"；最小可运行尺寸是 62×18）。
- 本 DSH 网页界面里跑不了 TUI —— 请在你自己的终端窗口里执行下面的命令。

## 1. 启动

仓库根目录下有一个**跨平台启动脚本**，Linux / macOS / WSL2 用法完全一样：

```bash
cd <仓库目录>        # 例如 /mnt/d/code_study/DND、~/code/dnd
./play.sh            # 启动游戏
./play.sh --check    # 只想看环境报告、不启动游戏（排障第一步）
```

脚本会先替你把常见坑拦住：平台（原生 Windows 直接给 WSL2 安装步骤）→ Python 版本与 `curses` →
是否真实终端 → 终端编码（不是 UTF-8 且系统有可用 UTF-8 locale 时自动补上）→ 窗口尺寸，
全部通过后才启动游戏。任何一步不通过都会给出中英文的**可操作**提示，退出码 2。

不想用脚本、或脚本都过不了自检时，直接调包也是一样的：

```bash
python3 -m dnd
```

启动后先看到**开始页**：`新的冒险 / 读取存档 / 名人堂 / 退出游戏`，**↑↓** 移动光标、**回车**确认
（也可以按 **1-4** 直选、**Esc** 退出）。选「新的冒险」进建角，选「读取存档」进存档管理。
常用变体（`./play.sh` 与 `python3 -m dnd` 参数完全一致）：

```bash
./play.sh --seed 42 --name Aria --class wizard --race elf   # 三个都给出才跳过开始页直接开局；只给一部分会进建角并预填
./play.sh --latest        # 接着最近一次存档玩（跳过开始页）
./play.sh --menu          # 参数再全也先回开始页
./play.sh --modern        # 现代模式：可免死一次
./play.sh --debug         # 调试键：x 显示全图，t 传送
```

想先看看有哪些存档、又不想进游戏？**不用输命令**：开始页选「读取存档」，或在游戏里按 **Esc** →
「存档管理」。`--list-saves` 仍然保留，是给脚本用的。

| 键 | 作用 |
|---|---|
| **↑ / ↓** | 在列表里上下选（到顶/到底会停住，长列表自动滚动，行尾有 `↑n` / `↓n` 提示） |
| **回车** | 读取选中的存档并立刻开始玩 |
| **D** | 删除选中的存档 —— 会先弹确认框，**默认停在「取消」**，一路敲回车不会误删 |
| **Esc** | 返回上一层（开始页 / 暂停菜单） |

存档摘要（角色名、职业、等级、深度、回合、金币、保存时间）来自存档里的 `_meta` 字段；
**旧存档没有这个字段也能列出来**，界面会退回文件名与修改时间显示。文件损坏的存档会标成
「损坏」，仍然可以选中并删掉 —— 不需要回命令行手动删文件。

## 2. 建角（30 秒）

| 步骤 | 操作 |
|---|---|
| ① 取名字 | 直接打字（≤14 字符，可留空自动叫"冒险者"） |
| ② 选职业 | **↑ / ↓** 在左侧"职业"栏选择：战士 / 法师 / 牧师 / 盗贼 |
| ③ 切到种族栏 | **Tab**（或 **Shift+Tab** / ← →） |
| ④ 选种族 | **↑ / ↓** 在右侧"种族"栏选择：人类 / 精灵 / 矮人 / 侏儒 |
| ⑤ 开始 | **回车** |

**哪一栏是"活的"一眼可辨**：活动栏当前项整行反白并带 `▸`，另一栏只用 `·` 标出当前选择——
屏幕上永远只有一个 `▸`，它就是 ↑↓ / 1-4 会动的那一栏。

两栏下方会实时显示说明与合成数值（"预览"框里），例如 `精灵·法师 生命骰 d6 初始生命 +3 每级法力 3` / `视野 10 敏捷 +2 体质 -1`。
按 **1-4** 可在当前栏位里直选，**Esc** 退出。

地图上只能看见**视野半径内**（基础 9 格，精灵/侏儒 +1）的东西；走过的地方会留下暗色记忆，敌人和物品只在可见时显示。
地形字形固定用 ASCII（`# . + > <`），配色负责表现远近层次，所以换成什么终端都不会错位。

> **框线显示错乱？** 框线用的是 `─│┌┐` 这类字符，少数中文终端把它们当**两格宽**，版面就会撑破。
> 加 `--ascii`（或设环境变量 `DND_ASCII=1`）可整套换成 `- | +`，观感朴素但绝对对齐。
> 默认在 UTF-8 终端下用 Unicode 框线，非 UTF-8 终端自动退回 ASCII。

## 4. 键位总表

| 键 | 作用 | 键 | 作用 |
|---|---|---|---|
| **W A S D** | 移动（上左下右） | 方向键 / hjkl | 移动 |
| y u b n | 斜向移动 | `.` 或 `5` 或空格 | 原地等待一回合 |
| `>` | 站在下楼梯上时下潜 | `<` | 上楼梯回上一层 |
| `g` 或 `,` | 拾取脚下物品（金币自动入袋） | `i` | 背包：按 **a/b/c…** 使用/装备/喝/读 |
| `c` | 施法（法师/牧师）：按字母选法术 | `?` | 帮助页（含考据说明），任意键关闭 |
| `F5` 或 `Shift+S` | 存档 | `R` | 名人堂名册 |
| `P` | 切换侧栏"出处 L1/L2/L3"标记 | `Q` | 退出（会问确认） |
| `Esc` | **暂停菜单**：继续 / 保存 / 存档管理 / 返回开始页 / 退出 | `x` / `t` | 仅 `--debug`：显示全图 / 传送到某层 |

> 所有菜单都能**只用方向键 + 回车**走完：开始页、存档管理、暂停菜单、建角、确认框都是。
> 确认框里危险操作（退出、返回开始页、删存档）**默认停在「取消」**，按 **← →** 换选项。
## 5. 目标

**下到第 10 层，夺取「深渊遗物」，即为胜利。** 第 10 层有「深渊守卫」守着遗物，正面硬拼通常打不过——先升级、换装备、备好药水再去。
守卫守着遗物的同时也**会追着你跑**：把它引到远处，再回头冲进房间抢走遗物（**拿到即胜利，不必杀死它**）；
冲刺路上大概要挨一两下，所以血量和药水就是你的本钱。

死亡是**永久**的：角色会写进名人堂（`saves/roster.json`），存档被删除。想留一条命就加 `--modern`（可免死一次）。

## 6. 战斗与生存法则

| 机制 | 数值 |
|---|---|
| 命中判定 | d20 + 命中加值 ≥ 目标护甲（AC）；**掷出 20 暴击（双倍伤害），掷出 1 必定失手** |
| 你的护甲 | 10 + 护甲加值 + 敏捷调整值（皮甲 +2 / 镶钉 +3 / 锁子甲 +5 / 板甲 +7） |
| 视野 | 半径 9（精灵、侏儒 +1）；怪物有**仇恨半径 7**，超出就不再穷追 |
| 生命恢复 | **每 12 回合 +1 HP**；药水 1d8+2（强效 2d8+4），牧师可施治疗轻伤 |
| 升级 | 经验达阈值升级：加生命骰 + 体质调整，法师/牧师同时加 MP（阈值 15 / 45 / 100 / 190 / 320） |
| 掉落 | 金币、宝石、武器、护甲、药水、卷轴，越深越好 |

**四个种族（建角时选，预览框会实时显示合成数值）**

| 种族 | 初始加成 | 属性调整 |
|---|---|---|
| 人类 | 起始生命 +1、法力 +1 | 无 |
| 精灵 | 视野 +1、法力 +1 | 敏捷 +2、体质 −1 |
| 矮人 | 起始生命 +2 | 体质 +2、敏捷 −1 |
| 侏儒 | 起始法力 +2、视野 +1 | 智力 +1、敏捷 +1、力量 −1 |

**生存要点**

1. **别在开阔房间里被围**：狭窄走廊里一次只面对一个敌人，仇恨半径只有 7，退开几步怪就不追了。
2. **血低于一半就喝药**，不要留到最后一刻——暴击是世界的一部分。
3. 打不过就**上楼**（`<`）：层数不会重置你的进度，回血后再下来。
4. 法师/牧师：**MP 只够几次施法**，留给硬仗（法师魔法飞弹必中、闪电束 3d6；牧师祝福 +2 命中）。
5. 每层探索到一半左右找下楼梯，**不要强求清空全层**——经验与宝物在更深处更划算。
6. 死人不会复活，但 `--seed` 相同就能重开同一座地牢，用来练路线。

## 7. 存档 / 名人堂 / 复现

```bash
python3 -m dnd --list-saves     # 列出所有存档（saves/*.json）——脚本用；游戏里直接用「读取存档」界面
python3 -m dnd --latest         # 读最近一次存档继续
python3 -m dnd --roster         # 打印名人堂
```

- 游戏内 `F5` 存档，`R` 看名人堂；`Esc` →「存档管理」可以**在游戏里读档/删档**，不必退出重开。
- 存档管理界面会显示每个存档的角色、等级、深度、回合、金币与保存时间；损坏的存档会标成「损坏」，选中后按 `D` 删掉。
- 结局画面会显示**种子**（如 `种子 12345`），用 `python3 -m dnd --seed 12345` 就能重开同一座地牢。
- 存档是纯 JSON，包含角色、地牢与随机数状态；同一存档 + 同一操作序列，结果完全可复现（内核是确定性的）。

## 8. 常见问题

**提示"终端窗口太小"？** 放大窗口到至少 62×18，建议 ≥100×30。

**在 Windows 的 cmd/PowerShell 里报错？** Windows 原生 Python 没有标准库 `curses`，那里跑不了。请在 **WSL2** 终端里跑：
先以管理员身份打开 PowerShell 执行 `wsl --install -d Ubuntu`（装完重启），然后在 Windows 终端里输入 `wsl` 进入发行版，
再 `cd` 到仓库目录执行 `./play.sh`。`./play.sh` 在原生 Windows 环境下也会直接给出这段指引。

**不确定环境哪里不对？** 先跑 `./play.sh --check`：它会一次打印平台、解释器版本、curses 是否可用、
是否是真实终端、`TERM`/编码/locale、窗口尺寸、存档目录。报 bug 时请把这份报告一起贴上。

**没有图形界面（比如 SSH/CI）想验证？**
```bash
python3 -m dnd --headless-demo 300 --seed 5     # 无界面跑 300 回合并打印状态
python3 tools/sim.py --runs 60 --class warrior  # 机器人跑批统计
```

**想换数值/加怪物？** 全部在 `dnd/data/*.json`（职业/种族/怪物/物品/法术），改完直接生效，不用改代码；每个文件里的 `_meta` 标了出处与可信度分级。

**字体/颜色怪怪的？** 加 `--no-color` 关掉颜色；加 `--ascii` 把框线/进度条换成纯 ASCII（中文终端把 `─│` 当两格宽时用这个，见第 3 节）。

**想删掉一个存档 / 看看还有哪些存档？** 不用敲命令：开始页选「读取存档」，或游戏里按 `Esc` →「存档管理」，
↑↓ 选、回车读、`D` 删（会问一次，默认「取消」）。

**界面上的 `#` `.` `+` `>` `<` 是什么意思？** 墙 / 地面 / 门 / 下楼梯 / 上楼梯。地图框的下边框上有一行同样的图例，不记得时看那里就行。
