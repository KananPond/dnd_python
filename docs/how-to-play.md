# 怎么游玩 · dnd 上手指南

> 面向第一次打开游戏的玩家。安装/开发说明见 [`../README.md`](../README.md)，机制出处见
> [`research-dossier.md`](research-dossier.md)。本文里的界面示意图都是从当前代码实际渲染出来的
> （不是手工画的），终端尺寸取 104×32 / 118×32。

## 0. 前置条件

- **必须是真实终端**：Linux / macOS 的终端，或 Windows 上的 **WSL2** 终端（原生 cmd/PowerShell **不支持** curses）。
- Python ≥ 3.10。**不需要装任何第三方包**。
- 建议终端窗口 **≥ 100 列 × 30 行**（宽度 ≥ 100 会多出一整栏「冒险者档案」）；最小可运行尺寸是 **62×18**。
- 本 DSH 网页界面里跑不了 TUI —— 请在你自己的终端窗口里执行下面的命令。

## 1. 启动

仓库根目录下有一个**跨平台启动脚本**，Linux / macOS / WSL2 用法完全一样：

```bash
cd <仓库目录>        # 例如 ~/code/dnd
./play.sh            # 启动游戏
./play.sh --check    # 只想看环境报告、不启动游戏（排障第一步）
```

脚本会先替你把常见坑拦住：平台（原生 Windows 直接给 WSL2 安装步骤）→ Python 版本与 `curses` →
是否真实终端 → 终端编码（不是 UTF-8 且系统有可用 UTF-8 locale 时自动补上）→ 窗口尺寸，
全部通过后才启动游戏。任何一步不通过都会给出中英文的**可操作**提示，退出码 2。

不想用脚本、或脚本都过不了自检时，直接调包也是一样的（脚本只做前置校验，不碰游戏逻辑）：

```bash
python3 -m dnd
```

常用变体（`./play.sh` 与 `python3 -m dnd` 参数完全一致）：

```bash
./play.sh --seed 42 --name Aria --class wizard --race elf   # 三个都给出才跳过开始页直接开局；只给一部分会进建角并预填
./play.sh --load saves/aria.json   # 直接读指定存档（跳过开始页）
./play.sh --latest                 # 接着最近一次存档玩（跳过开始页）
./play.sh --menu                   # 参数再全也先回开始页
./play.sh --modern                 # 现代模式：可免死一次
./play.sh --debug                  # 调试键：x 显示全图，t 传送
./play.sh --no-color               # 关闭颜色
./play.sh --ascii                  # 框线/进度条换纯 ASCII（中文终端把 ─│ 当两格宽时用）
./play.sh --no-prologue            # 跳过建角后的背景故事，直接进地牢
./play.sh --lore                   # 不上界面，直接在终端里打印背景故事
```

## 2. 开始页

启动后的第一屏，**全部用 ↑↓ 操作，不用记命令**：

```
                                         #####   ##   #  #####
                                         #    #  ###  #  #
                                         #    #  #  ###  #  ##
                                         #####   #   ##  #####

                                                深渊地牢
                              PLATO（1975）《dnd》现代复刻 · 零依赖终端版
                               下到第 10 层夺取「深渊遗物」，再活着回来。


                             ┌─  深渊地牢 · 开始  ────────────────────────┐
                             │ ▸ 新的冒险       选择职业与种族，进入地牢  │
                             │   读取存档                       4 个存档  │
                             │   名人堂                       1 位冒险者  │
                             │   退出游戏                            Esc  │
                             │ 选择职业与种族，进入地牢                   │
                             │ ↑↓ 选择   回车 确认   1-4 直选   Esc 退出  │
                             └────────────────────────────────── 回车开始 ┘
```

| 键 | 作用 |
|---|---|
| **↑ / ↓** | 在菜单里上下移动（到顶/到底会循环） |
| **回车**（或空格） | 确认当前项 |
| **1-4** | 直接选第 1~4 项 |
| **Esc** | 退出游戏 |

| 菜单项 | 会发生什么 |
|---|---|
| **新的冒险** | 进入建角界面（第 4 节），建角完成后接序章（第 5 节） |
| **读取存档** | 进入存档管理；右侧数字是当前存档个数 |
| **名人堂** | 只读地显示历史战绩（最近 14 条） |
| **退出游戏** | 直接结束，无确认 |

## 3. 存档管理

开始页选「读取存档」，或在游戏内按 **Esc →「存档管理」**，都会进这个界面。
**左列表右档案**：不用读档就能看到每个角色的进度。

```
    ┌─ 存档管理 ───────────────────────────────────────────────────────────────────────────────────┐
    ├──────────────────────────────────────────────────────────────────────────────────────────────┤
    │  Aria  Lv4                   09-11 23:54    ┬─────────────────┴                              │
    │  Borin  Lv4                  09-11 23:54      精灵·法师 4级                                  │
    │  broken  损坏                09-11 23:54      生命 19/31                                     │
    │  Nix  Lv4                    09-11 23:54                                                     │
    │                                               深度 ███░░░░░░░ 3/10                           │
    │                                               回合 511    金币 268                           │
    │                                                                                              │
    │                                               存档 aria.json                                 │
    │                                               时间 2026-09-11 23:54                          │
    │                                                                                              │
    └───────────────────────────────────────────────────────────────────────────────── 共 4 个存档 ┘
     ↑↓ 选择 回车 读取 D 删除 Esc 返回
```

| 键 | 作用 |
|---|---|
| **↑ / ↓** | 在列表里上下选（到顶/到底会停住，不会绕回） |
| **Home / End** | 跳到第一个 / 最后一个存档 |
| **回车** | 读取选中的存档并立刻开始玩 |
| **D** | 删除选中的存档 —— 先弹确认框，**默认停在「取消」**，一路敲回车不会误删 |
| **Esc** 或 **Q** | 返回上一层（开始页 / 暂停菜单） |

- 列表按**最近保存**排序，最新一档在最上面。存档多到一屏放不下时自动滚动，行尾会出现 `↑n` / `↓n` 提示。
- 右侧档案显示：角色名、种族·职业与等级、生命、深度进度条、回合、金币、文件名与保存时间；
  打到第 10 层还会多一行「已抵达最深处」。
- 摘要来自存档里的 `_meta` 字段；**旧存档没有这个字段也能列出来**，界面会退回文件名与修改时间显示。
- 文件损坏的存档会标成「损坏」，仍然可以选中并删掉 —— 不需要回命令行手动删文件。
- 读取失败时（文件被移动、结构不对）会在底栏给一句提示，不会把界面弄崩。

## 4. 建角（30 秒）

```
  ┌─ DND · 创建冒险者 ──────────────────────────────────────────────────────────────────────────────┐
  │ 姓名 Aria_                                                                                      │
  │                                                                                                 │
  │ ┌─ 职业 ─────────────────────┐    ┌─ 种族 ─────────────────────┐                                │
  │ │   1. 战士                  │    │   1. 人类                  │                                │
  │ │ ▸ 2. 法师                  │    │ · 2. 精灵                  │                                │
  │ │   3. 牧师                  │    │   3. 矮人                  │                                │
  │ │   4. 盗贼                  │    │   4. 侏儒                  │                                │
  │ └────────────────────────────┘    └────────────────────────────┘                                │
  │                                                                                                 │
  │  血少但能施法，法术是主要输出。                                                                 │
  │  夜视：视野半径 +1，敏捷 +2、体质 -1。                                                          │
  │ ┌─ 预览 ──────────────────────────────────────────────────────────────────────────────────────┐ │
  │ │ 精灵·法师     生命骰 d6     初始生命 +3    每级法力 3                                       │ │
  │ │ 视野 10    敏捷 +2 体质 -1                                                                  │ │
  │ └─────────────────────────────────────────────────────────────────────────────────────────────┘ │
  │  目标：下到第 10 层夺取「深渊遗物」，活着回来。                                                 │
  │  ↑↓ 选择    Tab / ←→ 切换职业与种族    1-4 直选    回车开始    Esc 退出                         │
  └─────────────────────────────────────────────────────────────────────────────────────────────────┘
```

| 步骤 | 操作 |
|---|---|
| ① 取名字 | 直接打字（≤14 字符，可留空，留空就叫「冒险者」；Backspace 删除） |
| ② 选职业 | **↑ / ↓** 在左侧「职业」栏选择（或按 **1-4** 直选） |
| ③ 切到种族栏 | **Tab**（或 **Shift+Tab** / **← →**） |
| ④ 选种族 | **↑ / ↓** 在右侧「种族」栏选择（或 **1-4** 直选） |
| ⑤ 开始 | **回车**；想放弃就按 **Esc**（回到开始页） |
| ⑥ 读序章 | 建角完成后先展示背景故事（第 5 节）：**回车**翻页读完，或 **Esc** 跳过 |

**哪一栏是"活的"一眼可辨**：活动栏当前项整行反白并带 `▸`，另一栏只用 `·` 标出当前选择——
屏幕上永远只有一个 `▸`，它就是 ↑↓ / 1-4 会动的那一栏。两栏下方会实时显示职业与种族的说明，
以及「预览」框里的合成数值（生命骰、初始生命、每级法力、视野半径、属性调整）。

窗口太矮时，提示 / 预览 / 说明会依次让位，但「姓名 + 两个选项栏 + 底部键位」永远保留。

**四个职业**

| 职业 | 生命骰 | 每级法力 | 法术 | 特点 |
|---|---|---|---|---|
| 战士 | d10 | 0 | —— | 命中成长最快（每级 +1），不会法术 |
| 法师 | d6 | 3 | 魔法飞弹 / 护盾 / 闪电束 | 法术是主要输出，血最少 |
| 牧师 | d8 | 2 | 治疗轻伤 / 祝福 | 能自愈，对**不死生物**命中 +2 |
| 盗贼 | d8 | 0 | —— | 无特殊机制，靠属性与装备 |

**四个种族**（预览框会实时显示合成数值）

| 种族 | 初始加成 | 属性调整 |
|---|---|---|
| 人类 | 起始生命 +1、法力 +1 | 无 |
| 精灵 | 视野 +1、法力 +1 | 敏捷 +2、体质 −1 |
| 矮人 | 起始生命 +2 | 体质 +2、敏捷 −1 |
| 侏儒 | 起始法力 +2、视野 +1 | 智力 +1、敏捷 +1、力量 −1 |

> 属性是 3d6 掷出来的（每项最低 6），职业主属性额外 +2；种族调整作用在其后，范围夹在 3~18。
> 起始金币 30。

图上还能看到：`@` 是你，`#` 墙，`.` 地面，`+` 门，`>` 下楼，`<` 上楼，`$` 金币，`*` 宝石/遗物，
`!` 药水，`?` 卷轴，`)` 武器，`[` 护甲，字母是怪物（`s` 骷髅、`O` 食人魔……）。

- ① 标题栏：身份、当前层数、深度进度条（已下潜几层）、回合数；`--debug` 时还会多一个 `[调试]` 标记。
- ② 体征栏：生命/法力/经验条、护甲、金币。窗口变窄时**从右往左整段丢弃**，不会留下半截字。
- ③ 地图视口：以玩家为中心滚动。**只能看见视野半径内**（基础 9 格，精灵/侏儒 +1）的东西；
  走过的地方留下暗色记忆，敌人和物品只在可见时显示。上下楼梯在框外时，边框上会标出方向。
- ④ 侧栏：宽度 ≥ 100 才有；显示角色卡、视野内敌人（最多 6 个）、装备、属性、状态增益、背包前 7 件。
  按 `P` 还能在底部追加出处标记（L1/L2/L3）。
- ⑤⑥ 日志区与⑦按键提示栏：日志保留最近 5 条，最新的加粗、越旧越暗。

地形字形固定用 ASCII（`# . + > <`），配色负责表现远近层次，所以换成什么终端都不会错位。

> **框线显示错乱？** 框线用的是 `─│┌┐` 这类字符，少数中文终端把它们当**两格宽**，版面就会撑破。
> 加 `--ascii`（或设环境变量 `DND_ASCII=1`）可整套换成 `- | +`，观感朴素但绝对对齐。
> 默认在 UTF-8 终端下用 Unicode 框线，非 UTF-8 终端自动退回 ASCII。
> 颜色不对/太花？加 `--no-color`。

## 7. 键位总表

| 键 | 作用 | 键 | 作用 |
|---|---|---|---|
| **W A S D** | 移动（上左下右） | 方向键 / `hjkl` | 移动 |
| `y u b n` | 斜向移动 | `.` 或 `5` 或空格 | 原地等待一回合 |
| `>` | 站在下楼梯上时下潜 | `<` | 上楼梯回上一层 |
| `g` 或 `,` | 拾取脚下物品（金币自动入袋） | `i` | 背包：按 **a/b/c…** 使用/装备/喝/读 |
| `c` | 施法（按字母选法术） | `?` | 帮助页（含考据说明），任意键关闭 |
| `F5` 或 `Shift+S` | 存档（成功后日志里给出路径） | `R` | 名人堂名册 |
| `P` | 切换侧栏「出处 L1/L2/L3」标记 | **`B`** | 重看序章（背景故事，第 5 节） |
| `Q` | 退出（弹确认框，默认「取消」） | `Esc` | **暂停菜单**：继续 / 保存进度 / 存档管理 / 返回开始页 / 退出 |
| `x` / `t` | 仅 `--debug`：显示全图 / 传送到某层 | | |

> 所有菜单都能**只用方向键 + 回车**走完：开始页、存档管理、暂停菜单、建角、确认框都是。
> 游戏内菜单还接受 `w/s`、`k/j` 作为上下；确认框里危险操作默认停在「取消」，按 **←→** 换选项。
> 帮助页里写的「退出 Q（直接退出）」是文案简写——实际按 `Q` 会先弹确认框。

## 8. 目标与终局

**下到第 10 层，夺取「深渊遗物」，即为胜利。** 第 10 层有「深渊守卫」守着遗物
（AC 19 / 生命 10d8+20 / +11 命中 / 3d8+3 伤害），正面硬拼通常打不过——先升级、换装备、备好药水再去。

守卫守着遗物的同时也**会追着你跑**：把它引到远处，再回头冲进房间抢走遗物
（**拿到即胜利，不必杀死它**）；冲刺路上大概要挨一两下，所以血量和药水就是你的本钱。
遗物一定放在守卫**身边**（不会压在它脚下，否则等于必须杀掉打不过的 boss）。

死亡是**永久**的：角色会写进名人堂（`saves/roster.json`），存档被删除。想留一条命就加 `--modern`（可免死一次，
触发时会提示「现代模式赐予你最后一口气」，生命回到 1）。通关或阵亡后会出现结算画面，可以按 `n` 直接开新角色、
按 `Q`（或 Esc）退出。

## 9. 战斗与生存法则

| 机制 | 数值 |
|---|---|
| 命中判定 | d20 + 命中加值 ≥ 目标护甲（AC）；**掷出 20 暴击（双倍伤害），掷出 1 必定失手** |
| 你的命中加值 | 职业命中成长（战士每级 +1、法师最慢）+ 力量调整值，另加增益 |
| 你的护甲 | 10 + 护甲加值 + 敏捷调整值（皮甲 +2 / 镶钉 +3 / 锁子甲 +5 / 板甲 +7）+ 法术增益 |
| 视野 | 半径 9（精灵、侏儒 +1）；怪物有**仇恨半径 7**，超出就不再穷追；未察觉的怪每回合 4% 概率游荡 |
| 生命恢复 | **每 12 回合 +1 HP**；治疗药水 1d8+2，强效治疗药水 2d8+4，牧师可施「治疗轻伤」 |
| 升级 | 经验达阈值升级（15 / 45 / 100 / 190 / 320 / 500 …，之后每级 +1500）：生命骰 + 体质调整（至少 +1），施法职业同时加 MP |
| 掉落 | 金币、宝石、武器、护甲、药水、卷轴，按深度加权分层；越深越好 |
| 宝物 | 金币价值 = 5d10 + 深度×10；宝石 = 3d6×5 + 深度×10 |

**法术表**

| 法术 | 职业 | 耗魔 | 效果 |
|---|---|---|---|
| 魔法飞弹 | 法师 | 2 | 对最近的可见敌人造成 2d6 伤害（射程 8，必中） |
| 护盾 | 法师 | 3 | 15 回合内 AC +4 |
| 闪电束 | 法师 | 5 | 对最近的可见敌人造成 3d6 伤害（射程 10） |
| 治疗轻伤 | 牧师 | 2 | 恢复 1d8+2 生命 |
| 祝福 | 牧师 | 3 | 20 回合内命中 +2 |

**生存要点**

1. **别在开阔房间里被围**：狭窄走廊里一次只面对一个敌人，仇恨半径只有 7，退开几步怪就不追了。
2. **血低于一半就喝药**，不要留到最后一刻——暴击是世界的一部分。
3. 打不过就**上楼**（`<`）：层数不会重置你的进度，回血后再下来。
4. 法师/牧师：**MP 只够几次施法**，留给硬仗。魔法飞弹必中、闪电束爆发高；牧师的治疗能顶一轮。
5. 每层探索到一半左右找下楼梯（机器人跑批的经验值也印证：**不要强求清空全层**）。
6. 死人不会复活，但 `--seed` 相同就能重开同一座地牢，用来练路线。
7. 机器人跑批显示各职业平均只能下到第 2~5 层，**死亡是常态**——把它当 roguelike 玩，而不是当通关挑战。

## 10. 存档 / 名人堂 / 复现

```bash
python3 -m dnd --list-saves     # 列出存档文件（脚本用；游戏里直接用「读取存档」界面）
python3 -m dnd --latest         # 读最近一次存档继续
python3 -m dnd --roster         # 打印名人堂
```

- 游戏内 `F5`（或 `Shift+S`）存档，`R` 看名人堂；`Esc` →「存档管理」可以**在游戏里读档/删档**，不必退出重开。
- 存档是纯 JSON，写在仓库的 `saves/` 下，**按角色名一人一档**（名字会被规整成小写字母数字）。
- 存档顶层带 `_meta` 摘要；旧存档没有它也能读、也能列。写入是原子的（先写 `.tmp` 再替换），不会写坏半份。
- 结局画面会显示**种子**，用 `python3 -m dnd --seed <种子>` 就能重开同一座地牢。
- 内核是确定性的：同一存档/种子 + 同一操作序列，结果完全可复现（本局命令都记在存档里）。

## 11. 常见问题

**提示「终端窗口太小」？** 放大窗口到至少 62×18，建议 ≥ 100×30。

**在 Windows 的 cmd/PowerShell 里报错？** 原生 Python 没有标准库 `curses`，那里跑不了。请在 **WSL2** 终端里跑：
管理员 PowerShell 执行 `wsl --install -d Ubuntu`（装完重启），在 Windows 终端里输入 `wsl` 进入发行版，
再 `cd` 到仓库目录执行 `./play.sh`。`./play.sh` 在原生 Windows 环境下也会直接给出这段指引。

**不确定环境哪里不对？** 先跑 `./play.sh --check`：它会一次打印平台、解释器版本、curses 是否可用、
是否是真实终端、`TERM`/编码/locale、窗口尺寸、存档目录。报 bug 时请把这份报告一起贴上。

**没有图形界面（比如 SSH/CI）想验证？**
```bash
python3 -m dnd --headless-demo 300 --seed 5     # 无界面跑 300 回合并打印状态与状态哈希
python3 -m dnd --lore --name Aria            # 只打印序章（不需要终端界面）
python3 tools/sim.py --runs 40 --class warrior  # 机器人跑批统计
```

**建角之后那段背景故事能重看或跳过吗？** 能。进游戏后随时按 **B** 重看（同一个界面、同一份数据）；
不想读就加 `--no-prologue`，或建角后按 **Esc** 跳过；想在终端里读纯文本版用 `--lore`。

**想换数值/加怪物？** 全部在 `dnd/data/*.json`（职业/种族/怪物/物品/法术），改完直接生效，不用改代码；
每个文件里的 `_meta` 标了出处与可信度分级，数据本身是 CC0-1.0。
游戏内序章在 `dnd/data/lore.json`（同样 CC0），完整世界观（诸神/种族/职业/遗物/时间线）在
`docs/world-setting.md`；改这两处就能换成你自己的设定，不必动一行代码。

**字体/颜色怪怪的？** 加 `--no-color` 关掉颜色；加 `--ascii` 把框线/进度条换成纯 ASCII
（中文终端把 `─│` 当两格宽时用这个，见第 6 节末尾）。

**想删掉一个存档 / 看看还有哪些存档？** 不用敲命令：开始页选「读取存档」，或游戏里按 `Esc` →「存档管理」，
↑↓ 选、回车读、`D` 删（会问一次，默认「取消」）。

**界面上的 `#` `.` `+` `>` `<` 是什么意思？** 墙 / 地面 / 门 / 下楼梯 / 上楼梯。地图框的下边框上有一行同样的图例。

**为什么我按了 `Q` 没退出？** `Q` 会先弹确认框，且默认光标停在「取消」；按 `←→` 选「确定」再回车。

**读档后装备标记不见了？** 这是曾经出现过的缺陷（装备副本未与背包关联），已修复并有回归测试
（`tests/test_core.py::test_equipment_is_relinked_to_inventory_after_load`）。若再遇到请附上存档文件与命令。
