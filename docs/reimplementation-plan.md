# 复刻计划：PLATO《dnd》(1975) 现代重制

> 目标不是 1:1 移植（原版 TUTOR 源码、PLATO 硬件时序、原始数值大多不可得），而是**机制骨架忠实 + 形式现代化**的可玩作品。
> 依据：`docs/research-dossier.md`（数据底稿与可信度分级）。

## 0. 目标 / 非目标

**要做**
- 单屏字符地牢（原生 64×32 网格）、俯视视角、局部视野、逐层下潜。
- 建角 → 属性/职业/等级/经验 → 战斗/法术/物品 → 宝物与进度 → 永久死亡 → 角色名册。
- 角色跨会话持久化（本地存档 + 导入导出）。
- 确定性内核：同一种子 + 同一输入序列 → 完全一致的重放（可测试、可回放、可压测）。
- 离线可跑、零第三方依赖（本机无外网，npm 无法安装）。

**不做（本轮）**
- TUTOR 源码级复刻、PLATO 主帧时序/多用户同时在线、原版数值 1:1 复现、联网多人。

## 1. 技术选型（受"无外网 + 零依赖"约束）

| 层 | 选择 | 理由 |
|---|---|---|
| 语言 | 现代 JavaScript ESM（`.mjs`）+ JSDoc 类型注解（`// @ts-check`） | 浏览器与 Node 直接共用源码，**无需构建步骤**（本机无 tsc/vite/esbuild） |
| 渲染 | Canvas 2D，逻辑分辨率 **512×512**，8×16 位图字形表（内置、十六进制字符串），`imageSmoothingEnabled=false` + CSS 整数倍放大 | 复刻 PLATO 观感，零美术素材、零字体文件 |
| 视觉风格 | 黑底 + 等离子橙辉光（多层描边/阴影近似 CRT 泛光），可选扫描线 | 单色屏的年代感 |
| 内核 | 纯函数 + 不可变状态快照 + 事件日志 | 可回放、可测试 |
| 随机 | 自带 seeded PRNG（mulberry32/xoshiro），内核内**禁用 Math.random / Date.now** | 确定性 |
| 测试 | Node 内置 `node:test` + `node:assert` | 零依赖 |
| 服务器 | Node 内置 `node:http` 静态服务器（`tools/serve.mjs`，端口 **8123**，避开 DSH 的 8080） | 零依赖 |
| 存档 | localStorage/IndexedDB + JSON 导入导出（模拟原版"角色记录"） | 现代化 |
| 音频 | WebAudio 合成方波/噪声音效，默认关闭 | 可关可开 |

## 3. 保真度策略（"不 1:1"的落地办法）

三级标注，写进数据文件与文档：

- **L1 忠实层**：有据可查的骨架 —— 64×32 单屏地牢、俯视、逐层下潜、角色持久化、永久死亡、掷骰战斗、宝物驱动成长、单键命令操作。
- **L2 现代化层**：键位与操作、教程/帮助、视野与信息面板、存档/导入导出、可访问性（字号、色觉模式、速度）、可撤销的误操作提示。
- **L3 自由发挥层**：具体职业/法术/怪物/数值/关卡布局/胜负条件（原版数据不可得，由我们定义）。

**数据出处登记**：每个内容条目附 `{"confidence": "documented|inferred|invented", "source": "<url|note>"}`；
界面提供「考据模式」开关：开启后在状态栏显示当前所见内容的出处等级 —— 既诚实，也让"哪些是原版、哪些是我们的再创作"一目了然。

**合规**：不使用 TSR/WotC 的商标与专有名词（不出现 D&D 品牌标识）；怪物/物品使用公有领域的通用奇幻词汇或自创名。

## 4. 复刻要素 → 实现方式（保真度矩阵）

| 原版要素（可信度） | 我们的做法 | 层级 |
|---|---|---|
| 512×512 / 64×32 字符屏（A） | Canvas 逻辑 512×512、8×16 字模、整数倍放大、无插值 | L1 |
| 等离子橙单色辉光（A-） | 黑底橙字 + 泛光/扫描线可选 | L1 |
| TUTOR 教学语言（A） | 不还原语言；用数据驱动 + 纯函数内核实现同等逻辑 | L2 |
| PLATO 功能键（NEXT/HELP…）（A-） | 屏幕内虚拟功能键面板 + 键盘映射（含 F1 帮助） | L1/L2 |
| 局部视野的地牢探索（B） | FOV（射线/阴影投射）+ 记忆雾 | L1 |
| 掷骰式战斗与职业差异（B） | d20 风格结算，职业/等级影响命中与伤害 | L1/L3 |
| 法术（C） | 自定法术表（数据文件），预留替换接口 | L3 |
| 多层地牢（B/C） | 10 层，程序生成房间+走廊，深度控制怪物与宝物表 | L1 结构 / L3 数值 |
| 永久死亡（B） | 死亡即角色封存进"名册（Hall of Fame）"，可选"现代模式"提供一次复活 | L1 + L2 选项 |
| 角色持久化（B+） | 本地存档 + JSON 导入导出 + 多角色槽位 | L1/L2 |
| 目标/通关（C） | 第 10 层守护者 + 终极宝物，取得后生还即通关并记录名册 | L3 |
| 玩家社群/排行榜（B+） | 本地名册 + 可分享的战报字符串（种子+成绩） | L2 |

## 5. 里程碑（每步都有可测验收）

**M0 资料定档（本次交付）**
- 产出 `docs/research-dossier.md`（可信度分级）与本文档；建立"假设登记表"（C 类空白位的默认取值与理由）。
- 验收：每条数据要么有来源链接，要么被显式标记为 inferred/invented。

**M1 骨架可跑**
- 内容：seeded PRNG、64×32 网格与字模渲染、地图生成（房间+走廊）、FOV、移动/楼梯、状态面板、静态服务器。
- 验收：浏览器里能用方向键走动并上下楼；同种子地图可复现；`node tools/sim.mjs` 能无 UI 跑通 100 层生成无断言失败。

**M2 角色与战斗闭环**
- 内容：建角（职业/属性/掷骰）、战斗结算、怪物 AI、掉落、经验与升级、物品与装备、死亡流程。
- 验收：能完整打完一层并升级；战斗结果在同种子下可重放一致；单元测试覆盖伤害/命中/升级边界。

**M3 内容与进度**
- 内容：10 层难度曲线、怪物/宝物分层表、陷阱与门锁、法术实装、第 10 层目标与通关流程。
- 验收：机器人跑批 200 局产出胜率/平均深度/死亡原因分布；无死局（每层可达楼梯，生成器连通性断言 100% 通过）。

**M4 观感与操作（PLATO 味）**
- 内容：字模美术打磨、辉光/扫描线、消息日志、虚拟功能键、帮助页、WebAudio 音效（默认关）、考据模式开关。
- 验收：1280×960 窗口下观感一致；键鼠全流程可玩；帮助页覆盖全部命令。

**M5 平衡与自动化**
- 内容：难度/经济/经验曲线调参，多策略机器人（随机/贪心/脚本）对比，回归阈值固化进测试。
- 验收：`node --test` 全绿；关键指标（首层死亡率、通关率）落在设计区间。

**M6 存档 / 名册 / 调试**
- 内容：多槽存档、导入导出、名册与战报分享串、调试面板（全图/传送/换种子/时间倒带）。
- 验收：导出→清空→导入后角色与地牢状态完全一致。

**M7 抛光交付**
- 内容：README（玩法/操作/开发/数据来源说明）、演示脚本、可选静态部署说明、变更记录。
- 验收：新用户 3 分钟内能开局；文档能自洽解释"哪些是原版、哪些是再创作"。

## 6. 测试与质量

- **确定性**：内核不触碰时钟/全局随机；`replay(seed, inputs)` 的状态哈希在测试中断言。
- **单元/属性测试**：地图连通性、FOV 对称性、伤害与护甲边界、经验表单调性、存档往返一致。
- **机器人压测**：`tools/sim.mjs --runs 1000 --policy greedy` 输出统计 JSON，进入回归基线。
- **可玩性检查表**：无鼠标可玩、无教程可玩（帮助页可达）、误操作可恢复、色觉友好模式。

## 7. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 原版数值不可得（最大） | 复刻"不像原版" | 保真度分级 + 数据文件可替换 + 考据模式；将来拿到资料只改 JSON |
| 无外网/无依赖 | 不能用现成框架 | 全自研零依赖栈；Node 内置测试与服务器 |
| 范围蔓延 | 交付遥遥无期 | M1–M4 定义为"最小完整可玩版"，M5+ 为增强 |
| 观感 vs 可玩性冲突 | 硬核劝退 | 「原味模式 / 现代模式」双预设 |
| 商标与版权 | 法律风险 | 不用 D&D 品牌与专有名词；仅用公有领域通用词 |
