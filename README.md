# dnd — PLATO(1975)《dnd》现代复刻（终端 TUI 版）

1975 年运行在 PLATO IV 系统上的地牢爬行游戏 **dnd**（Gary Whisenhunt & Ray Wood）的现代重制。
**不做 1:1 还原**：机制骨架忠实（L1）＋形式现代化（L2）＋内容再创作（L3），每条内容都在数据表里
标了可信度分级，考据过程见 [`docs/research-dossier.md`](docs/research-dossier.md)。

| 项 | 值 |
|---|---|
| 前端 | Python 标准库 **curses**（零第三方依赖，没装 pip 也能跑） |
| 内核 | 自研确定性内核：seeded PRNG，内核内不使用 `random` / `time`，TUI / 机器人 / 回放测试共用同一份逻辑 |
| 平台 | Linux / macOS / Windows 上的 **WSL2**（原生 Windows Python 没有 `curses`，不支持） |
| Python | ≥ 3.10（本轮实测于 3.14.4） |
| 规模 | 游戏本体 **3827 行** Python（其中界面 1984 行）＋工具 832 行＋测试 1402 行 |
| 验证 | **98 项**单元测试（内核 30 / TUI 62 / CLI 6）、**37 项** tmux 伪终端冒烟、17 个界面预览场景，本轮全部通过 |

## 快速开始

```bash
./play.sh                                         # 唯一推荐入口：Linux / macOS / WSL2 通用
./play.sh --check                                 # 只做环境自检并打印报告，不启动游戏（报 bug 时请附上它）
python3 -m dnd                                    # 等价入口：脚本只做前置校验，不碰游戏逻辑
```

启动后是**开始页**：`新的冒险 / 读取存档 / 名人堂 / 退出游戏`，**↑↓** 移动、**回车**确认（也可 **1-4** 直选、**Esc** 退出）。

- **新的冒险** → 建角：输入姓名 → ↑↓ 选职业 → `Tab` / `Shift+Tab` / `←→` 切到种族栏 → ↑↓ 选种族 → 回车开始
- **读取存档** → 存档管理：↑↓ 选、回车读、`D` 删（确认框默认停在「取消」），不需要输任何命令
- 游戏内按 **Esc** 打开暂停菜单：继续 / 保存进度 / 存档管理 / 返回开始页 / 退出

命令行参数是"老玩家快捷键"（也是伪终端冒烟测试依赖的路径）：

```bash
./play.sh --seed 42 --name Aria --class wizard --race elf   # 三个都给出才跳过开始页直接开局；只给一部分会进建角并预填
./play.sh --load saves/aria.json                  # 直接读指定存档
./play.sh --latest                                # 读最近一次存档（跳过开始页）
./play.sh --menu                                  # 参数再全也先回开始页
./play.sh --modern                                # 现代模式：免死一次
./play.sh --debug                                 # 调试键：x 显示全图，t 传送
./play.sh --no-color                              # 关闭颜色
./play.sh --ascii                                 # 框线/进度条退回纯 ASCII（中文终端把 ─│ 当两格宽时用）
./play.sh --list-saves                            # 列出存档文件（脚本用）
./play.sh --roster                                # 打印名人堂
./play.sh --headless-demo 300 --seed 5            # 无终端环境自检：跑 300 回合并打印状态
```

### 平台支持

| 系统 | 怎么跑 | 说明 |
|---|---|---|
| **Linux** | `./play.sh` | 需要 `python3`（≥ 3.10）。发行版若未自带：`sudo apt install -y python3` |
| **macOS** | `./play.sh` | 系统自带 `python3` 可能只有 3.9；用 `brew install python` 装新的，或 `DND_PYTHON=/opt/homebrew/bin/python3 ./play.sh` |
| **Windows** | **必须用 WSL2** | WSL 终端里 `cd` 到仓库后 `./play.sh`。原生 cmd/PowerShell/Git Bash **不支持**（原生 Python 没有标准库 `curses`）。安装：管理员 PowerShell 执行 `wsl --install -d Ubuntu`，重启后进入 `wsl` |

`play.sh` 的校验顺序固定为：平台（原生 Windows 直接给 WSL2 安装指引）→ Python 版本与 `curses` →
是否真实终端 → 终端编码（不是 UTF-8 且系统有可用 UTF-8 locale 时自动补上）→ 窗口尺寸，然后才 `exec python3 -m dnd`。
任何一步不过都给出可操作的中英文提示，**不会留下一个意义不明的 traceback**；自检失败时退出码为 2。

环境：Python ≥ 3.10（开发机 3.14）、支持 curses 的终端。建议窗口 **≥ 100×30**（宽度 ≥ 100 时右侧显示**冒险者档案**：
生命/法力/经验条、视野内敌人、装备、属性、背包）；最小可运行尺寸 **62×18**，再小会显示"终端窗口太小"。

## 操作

| 键 | 作用 | 键 | 作用 |
|---|---|---|---|
| **W A S D** / 方向键 / `hjkl` / `yubn` | 移动（`yubn` 为斜向） | `.` 或 `5` 或空格 | 原地等待一回合 |
| `>` | 站在下楼梯上时下潜 | `<` | 上楼梯回上一层 |
| `g` 或 `,` | 拾取脚下物品（金币自动入袋） | `i` | 背包（按字母使用/装备/喝/读） |
| `c` | 施法（按字母选择） | `?` | 帮助页（含考据说明），任意键关闭 |
| `F5` 或 `Shift+S` | 存档 | `R` | 名人堂名册 |
| `P` | 切换侧栏出处标记 | `Q` | 退出（确认框默认停在「取消」） |
| `Esc` | **暂停菜单**（继续/保存/存档管理/回开始页/退出） | `x` / `t` | 仅 `--debug`：显示全图 / 传送到某层 |

> 所有菜单都能**只用方向键 + 回车**走完：开始页、存档管理、暂停菜单、建角、确认框，一个不落。
> 危险操作（退出、返回开始页、删存档）的确认框**默认停在「取消」**，按 `←→` 换选项。

## 玩法

开始页 → 建角（4 职业 × 4 种族）→ 潜入 **10 层**地牢 → 探索、战斗、拾宝、升级 →
第 10 层夺取**深渊遗物**即胜利（守卫就守在遗物旁，**拿到即赢，不必杀死它**）。
死亡是**永久**的：角色写进名人堂（`saves/roster.json`），存档被删除；`--modern` 可免死一次。

| 机制 | 数值（全部来自 `dnd/data/*.json`，可整体替换） |
|---|---|
| 命中判定 | d20 + 命中加值 ≥ 目标 AC；**掷出 20 暴击（双倍伤害），掷出 1 必定失手** |
| 护甲 | AC = 10 + 护甲加值 + 敏捷调整值（皮甲 +2 / 镶钉 +3 / 锁子甲 +5 / 板甲 +7）+ 法术增益 |
| 视野 | 递归阴影投射，基础半径 **9**（精灵/侏儒 +1）＋记忆雾；怪物**仇恨半径 7**，超出不再穷追 |
| 生命恢复 | 每 **12 回合 +1 HP**；治疗药水 1d8+2，强效 2d8+4，牧师可施「治疗轻伤」 |
| 升级 | 经验达阈值升级（15 / 45 / 100 / 190 / 320 …，之后每级 +1500）：加生命骰 + 体质调整，施法职业同时加 MP |
| 掉落 | 金币、宝石、武器、护甲、药水、卷轴，按深度加权分层 |

**4 种族**（建角预览框实时显示合成数值）：人类（生命/法力各 +1）、精灵（视野 +1、法力 +1，敏捷 +2、体质 −1）、
矮人（生命 +2，体质 +2、敏捷 −1）、侏儒（法力 +2、视野 +1，智力 +1、敏捷 +1、力量 −1）。
**4 职业**：战士（d10 生命骰，无法术）、法师（d6，魔法飞弹/护盾/闪电束）、牧师（d8，治疗轻伤/祝福，对不死生物命中 +2）、盗贼（d8，无法术）。

法术表共 5 个法术（法师 3 / 牧师 2），另有 2 种伤害卷轴；12 种怪物按深度 1–10 加权分布，18 种物品。金币目前只作计分。

原版 dnd 的职业、法术、怪物、数值**均已不可考**（见研究档案第四节"未确证清单"）。因此：

| 层 | 内容 | 说明 |
|---|---|---|

| **L2 现代化** | 键位与帮助、视野与记忆雾、仇恨半径、生命自然恢复、上升式 AC、存档/名册、ASCII/无颜色降级 | 现代可玩性所需 |
| **L3 再创作** | 4 职业、4 种族、5 法术、12 怪物、18 物品与各自数值、10 层难度曲线、遗物结局 | 43 条内容全部标了 `confidence` 与 `_meta` |

## 存档与复现

- 存档是**纯 JSON**（角色 + 地牢 + RNG 状态），写在仓库的 `saves/` 下，按角色名一人一档。
- 顶层多一个 `_meta` 摘要字段（名字/职业/种族/等级/深度/回合/金币/生命/时间），**存档管理界面**直接用它显示，
  不必为了列一行摘要反序列化整份地牢；旧存档没有 `_meta` 也能列出，界面会退回文件名与修改时间。
- 写入是**原子**的（先写 `.tmp` 再 `os.replace`），不会因为写一半崩溃把存档写坏。
- 损坏的 JSON 仍会列出来并标成「损坏」，可以在界面里选中按 `D` 删掉，不需要回命令行。
- 结局画面会显示**种子**（如 `种子 12345`），`python3 -m dnd --seed 12345` 就能重开同一座地牢。
- 内核确定性：同一 `--seed` ＋ 同一操作序列，跨进程得到完全一致的状态哈希（`Game.state_hash()`）；
  本局执行过的命令（含 `--debug` 的 `x`/`t`）都会完整记进 `Game.commands`，`replay.run(seed, commands)` 能原样复现。

## 已知问题 / 路线图

- **平衡**：见上文「验证」一节的四职业跑批；法师偏弱、无人通关，属于调参工作（也可通过增强机器人策略验证）。
- **终局**：深渊守卫（AC 19 / 10d8+20 / +11 3d8+3）正面硬拼几乎打不过，设计意图是"引开它、再冲刺抢遗物"。
  守卫必定生成，遗物就放在它**身边**（不压在它脚下，否则等于必须先杀掉打不过的 boss 才能通关）。
- 金币目前只作计分，尚无商店/祭坛等消耗途径。
- 尚未实现：多角色槽位（仍是一人一档）、存档导入导出、通关回程（带遗物返回地面）、洞穴型/主题化层、
  陷阱与门锁、音效、i18n、分享串。
- 存档目录固定为仓库内 `saves/`，尚无 `DND_SAVE_DIR` 之类的位置覆盖。
- 尚未核实：原版的职业/法术/层数/胜利条件（拿到资料后只需替换 `dnd/data/*.json`，无需改代码）。
- 开发注意：`ui/theme.py` 在模块级 `import curses`，新增 UI 引用请照 `__main__.py` 的写法**延迟导入**，
  否则 `--headless-demo` / `--list-saves` 在没有 curses 的环境（Windows 原生 Python）会直接崩。
